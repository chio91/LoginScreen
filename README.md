# (C# 코딩) 로그인 화면

## 개요
- C# 프로그래밍학습
- 1줄소개: 아이디와 패스워드를 입력해야 하는 로그인 화면
- 사용한플랫폼: 
	- C#, .NET Windows Forms, Visual Studio, GitHub
- 사용한컨트롤:
	-TextBox, Button, Label
- 사용한기술과구현한기능:
	- Visual Studio를이용하여UI 디자인
	- 논리 연산자 사용으로 로그인 성공 여부 확인
	- Placeholder 기능 구현
	- 탭을 이용한 입력 포커스 제어
